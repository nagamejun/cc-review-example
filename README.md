# cc-review-example

CI上でClaude Codeがコードレビューを自動実行するための検討リポジトリです。

## 概要

このリポジトリは、CircleCIなどのCI環境においてClaude Codeを用いてプルリクエストの
コードレビューを自動化するための検証・検討を行う目的で作成されました。

## ファイル構成

| ファイル | 説明 |
| --- | --- |
| `base.yaml` | テスト用サンプルデータ（`test`キーや`id`フィールドを含む設定ファイル） |
| `src/app/text.md` | シークレット検出のテスト用サンプル（`password`フィールドを含む） |

これらのファイルはClaude Codeによる自動コードレビューの動作確認用サンプルです。
